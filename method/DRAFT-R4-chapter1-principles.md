## The two paragraphs

**These are the rules the work was done under.** They were assigned during the project, not derived from it: each one
was adopted when it was needed, and several were corrected when writing them down showed what they had actually been
saying. They are the foundation of the method rather than a result of it, and they are collected here so that a reader
can apply them, check them, or reject them.

**They divide by what they are, not by whether they can be written as an equation.** Some are *mechanisms* — facts
about an index, settled by a proof or a computation. Some are *operations* — things the worker does, settled by the
failure they prevent. Two are *relations* between the two, carrying content and taking no expression. Where a
principle has an exact form it is given; where it has none, saying so is better than manufacturing one.

## The twenty-three

| | principle | what it means, or how it is applied |
|---|---|---|
| **P1** | A complete index is self-referencing. | ℛ(Λ) = Λ. The index is a fixed point of its own closure operator. |
| **P2** | A complete index is self-defending. | ⅅ = dim q − rank ∂Φ/∂p ≥ 1, which holds exactly when the index derives more quantities than it assigns parameters. That surplus is the check. For Λ: dim p = 4, dim q = 6, rank 4, ⅅ = 2. Without surplus there is no check. |
| **P3** | When the path is not found, work backwards from the desired output to an established input. | Invert the map; if the fibre is not a single point, find the datum that separates it. |
| **P4** | Always audit results. | |
| **P5** | Always compute the result before assuming the result. | |
| **P6** | When a question is confusing, reframe the question. | |
| **P7** | All questions must close. | Closure needs a **well-founded measure**, not a shrinking count: the open-item count rose and fell across this work. The measure is the multiset of the open items' stakes, ordered *nothing < a novelty assessment < one stated claim < a result the book relies on*, which is well-founded and whose multiset extension is well-founded. So the principle forbids *claiming* coherence; it does not assert that gaps always close. |
| **P8** | Any true answer, good or bad, is a bound. | A failed attempt is a true answer and narrows what remains: a decreasing filtration. |
| **P9** | If the first dimension is a single all-encompassing definition, every other dimension is a perspective of it. | rank(log q) = 1. Its second and non-trivial instance is E itself, read three ways — forward as a diagnosis, backward as a prohibition, and as an outcome — three readings obtained separately whose identity had to be computed. |
| **P10** | Allow continued expansions. | A constraint of the admitted form preserves closure, so the index can be extended without being rebuilt. |
| **P11** | Close all gaps before continuing. | |
| **P12** | Every test must be run against every cell. | ρ = 0 is certain only when the number tested equals the whole index. A sample cannot establish it. |
| **P13** | Coherence cannot be claimed while any caveat, gap or contradiction stands. | COHERENT ⟺ the open set is empty. |
| **P14** | A structural problem suggests a structural solution. | |
| **P15** | For fetching: use the index to navigate; data can be retrieved in pieces. | |
| **P16** | Treat bounds, constraints and limits as coordinate values. | The one principle with no recorded failure behind it: it was adopted rather than learned, and has three constructive realisations in the work. |
| **P17** | The path is always through the bounds. | Following the bounds costs **one comparison per constraint** where searching the volume costs one per cell — seven comparisons against 976 cells for Λ, and against 199,130 at the top of the tower. The original form said 1/N and N was never defined; the corrected form carries no N. |
| **P18** | If the index is complete, a work that comprehends it completely is itself an index, and is itself self-referencing and self-defending. | Applied to this book by the chapter that indexes it. |
| **P19** | An index is complete only when there are no more questions left to answer about its contents. | COMPLETE(X) ⟺ Q(X) = ∅ — strictly stronger than closure. E = 0 says no cell the structure admits is absent; Q = ∅ says no question the contents admit is unanswered. Λ has had E = 0 since it was built and has never had Q = ∅. |
| **P20** | The language in which a question is posed bounds whether it can close, and at what cost. | |
| **P21** | Any definition contained within the lattice, and thus its equations, must be true in every mathematical language and in their combinations. | |
| **P22** | Because everything is defined in a complete index, the entirety of the index is visible. | The original added *and no lie can exist within it*, which is false: rebuilt around a fabrication the index still closes, still has E = 0, still satisfies every law here. What is true is that in a complete index every rule is content rather than inference, so a false cell is contradicted in the open by a stated rule where an inferred rule would have absorbed it. Altering a rule is equally visible. **A complete index converts deception into disagreement: error survives, concealment does not.** |
| **P23** | An object is complete only when both hold: all of its definitions are identified, and no question can ever be had about the definition of the object. | The first condition is checkable; the second is the one that keeps the work open. |

## Where the book's wording has drifted from what was assigned

Recorded from the same source, because M's direction is that the list carries *"their definition or how they are
applied"*, and the definition ought to be the one assigned:

- **P10 is the largest drift, and it changes the proposition.** M assigned *"allow for continued expansions of
  **this list** by me"* — a standing reservation that he may add principles. The book prints *"allow continued
  expansions"* with the expression *"§16.4-form constraints preserve closure"*, which is a mathematical claim about
  constraint forms. **These are different statements**, and the second is not a formalisation of the first. Worth
  M's decision: keep the original as the principle and move the constraint result to where it belongs, or state both.
- **P13 was narrowed.** M assigned five blockers — *caveat, gap, question, contradiction, assertion*. The book prints
  three: *"any caveat, gap or contradiction"*. Question and assertion were dropped.
- **P16 lost its second sentence**, *"Let the index show you the answers and the path to them"*, which is the
  operative half.
- **P15 was generalised.** M's was specifically about data behind paywalls or hard to find; the book's *"data can be
  retrieved in pieces"* is not in the original.
- **P17 lost two of its three nouns**: M assigned *"bounds, constraints, and limits"*; the book prints *"the bounds"*.

None of these is repaired here.
