## What is built (in the tree, unseated)

- **`method/members/census2.py`** — `census.py` row for row, with three changes and nothing else: the extent is data
  (`n not in regnums`), the members are read from the script's own directory, the output path is an argument (never the
  seated member). Runs in 20 s, standard library.
- **`tools/close_census2.py`** — `close_census.py`'s successor. The census is regenerated by RUNNING `census2.py`, and the fresh
  rows are matched onto the seated ids by CONTENT in four tiers, every pairing below the first printed with both texts:
  (1) exact — (class, member, item, detail) equal; (2) by item — (class, member, item) unique on both sides, the detail
  changed; (3) by text — the quoted line equal, only the tally prefix changed; (4) by run — the two quoted lines share a run
  of characters containing the item, at least six characters longer than it, longest run then nearest line. An old row
  still unmatched is GONE, and the tool REFUSES unless the id is named in `--retire`; a retired row is CARRIED — the seated
  row verbatim with its detail prefixed `RETIRED W-NNN: not measured at this build | ` — so that every cited id still
  resolves and the row says plainly it is no longer a measurement; it is carried by its mark on every later regeneration
  and never re-measured, and if the defect measures again it is a NEW row under a new id. Retirement is a ruling typed on
  the command line and recorded in the W text, never the tool's. New rows take ids above the seated maximum in
  measurement order. The rest is `close_census.py`'s discipline unchanged: W text to WORKING-REGISTER.md, MANIFEST.tsv
  recomputed, the change set asserted, the reverse guard recovering the old bundle's md5 before anything is written.
  `--dry` runs everything and writes nothing; `--seated PATH` on a `--save` output proves the regeneration a fixed point.
- **`tools/gate_live.py --census`** — the live census step: `close_census2.py --dry` must print `== the seated member`.
  `gate.py census` stays red by construction (`census.py`'s paths and literal; a seated member is never edited in place).
