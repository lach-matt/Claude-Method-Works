## What is the method?

The method is one question, asked of a body of knowledge: **are there any more questions left to ask?**

Not questions someone happens to raise — questions the material itself poses: a cell its own structure implies, a value its own relations demand. The method recodes a subject as an *index*, an ordering on coordinates that adds nothing not already known, and then asks whether that index has answered every question its own contents raise. When the answer is *none left*, the index is **closed**. When questions remain, it is **open**, and the number left over measures exactly how far it has to go.

Four moves, the same whatever the subject: build the index so it adds no new content; **close it** — reconstruct it from its own cells with the operator ℛ until nothing more is added; **read the defect** E, the count of what the reconstruction had to add, zero exactly when the index was already whole; and **record every failure**, because the list of what broke is the evidence the method works, not an apology for it.

A closed index — one where ℛ(Λ) = Λ, the index equal to its own reconstruction — is not merely a tidy one. Two of its properties give the method its teeth. It is **self-referencing**: it contains its own definition, so the rule for which cells belong can be read back off the cells already there. The periodic table cannot tell you that period 1 holds only two elements — you must be told; a closed index needs no such outside voice. And it is **self-defending**: because it carries more than the minimum needed to specify it, some quantities can be reached two independent ways, and where the two disagree an error shows. That is how the object in this book once caught its own author — a wrong nuclear charge its own product could not see, made loud by two quantities it carried but did not strictly need.

This is what the equation on the title page says. `E(X) = |ℛ(X)| − |X| = 0`: reconstruct the index from its own cells, count what that adds, and find it is nothing — the index was already complete. The line below, `|∏ᵢ Aᵢ| = |X| + E(X) + refused`, splits everything the coordinates could name into three — the cells present, the cells implied but not yet held, and the cells the structure refuses — which for this book's object reads 6,912 = 976 + 0 + 5,936. And `ℛ(Λ) = Λ` is the self-referencing law once more: the same quantity read as arithmetic, geometry, or order, with ℛ the mechanism by which those three languages say the one thing to each other.
