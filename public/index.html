    Provenance

    Reading this index

    The top level is the drawn periodic layout of section 6: 90 cells held, 126 admitted by ℛ, and the 36 the operator admits but the table does not hold drawn as dashed ghosts. Switch to the Janet layout to see the same elements on (n+ℓ, ℓ), where E = 0.

    Zoom into an element and its ions appear inside it, in spectroscopic order (I is neutral). Zoom into an ion and its eight ℓ channels appear; into a channel and its cells, one per multiplicity, coloured by grade. Every cell is a row of COORDINATES-2.13.

    Every value in the panel carries a status badge. READ is a measurement from a member or the mirror; PINNED the corpus defines it at the precision a program needs; DERIVED arithmetic on those, nothing added; RECOVERED measured out of the index's own computed column; RECONSTRUCTED the corpus states the object but not the form a program needs. A status is never flattened.

    Navigation

    • Scroll or pinch to zoom, drag to pan, click a node to fly to it.
    • Esc up one level · H whole index · / search · + − zoom · arrow keys pan.
    • Search accepts a symbol, Z, name, or a path: Fe II, Fe II d, Fe II d 3.
    • The address bar carries the path, so any node is a link.

    What this is not

    Nothing here is computed by the page. Every number is tools/populate.py's, serialised by tools/webindex.py, and the page does no arithmetic of its own. A finding is recorded, never repaired: where the spectra index disagrees with the observed configurations, both values are shown.
