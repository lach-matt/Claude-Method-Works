### The identity Ric(e₄, e₄) = −(3/Ω)(∂_v²Ω − 2∂_vW ∂_vΩ + |χ̂|²Ω/3) (l. 501–506)

**By hand.**
- Since dim = 3, γ = Ω²γ̂ gives det γ = Ω⁶ det γ̂. So Ω := (det γ/det γ₀)^(1/6) makes det γ̂ = det γ₀ in every chart.
  The ratio of determinants is chart-independent, and det γ₀ = 1/16 in (x, φ1, φ2).
- χ_A^B = γ^(BC)(Ω∂_vΩ γ̂_AC + Ω²∂_vγ̂_AC/2) = (∂_vΩ/Ω)δ_A^B + χ̂_A^B.
- tr χ̂ = ∂_v ln det γ̂ /2 = 0. So trχ = 3∂_vΩ/Ω and |χ|² = 3(∂_vΩ/Ω)² + |χ̂|².
- Substituting in −∂_v trχ + 2∂_vW trχ − |χ|² gives −3Ω″/Ω + 6W′Ω′/Ω − |χ̂|², which is the stated form.
- γ₀ = dx²/(4(1 − x²)) + ((1 + x)/2)dφ1² + ((1 − x)/2)dφ2² is the round metric: put x = cos 2ϑ in
  dϑ² + cos²ϑ dφ1² + sin²ϑ dφ2². It is O(4)-invariant, hence G-invariant.

**By computer algebra (private, my own code).** I did not reuse the first round's scripts.
- The test metric is a general five-dimensional metric in double-null form
  −2e^(2W)(du ⊗ dv + dv ⊗ du) + γ_AB(dy^A − b^A du)(dy^B − b^B du), with γ = Ω²·M·(det γ₀/det M)^(1/3).
  W, b^A, Ω and the symmetric M are random polynomials of (u, v, y), and γ₀ is a random metric of y alone.

### Is the writer right that the first reader's metric extension fails?

No, not for a smooth extension, and not even for a C¹ one. The writer's report says the claim "fails for a general
extension … (for example u′ = −c|u|^(1/2) from u = 0)". That example needs g̃⁻¹(dq, dq) ≳ |q|^(1/2) on the far side of
{q = 0}, which no C¹ extension can have.

The argument for any C¹ Lorentzian g̃ in which H = {q = 0} is null with ∇q past directed on H runs as follows.
- h := g̃⁻¹(dq, dq) is C¹ and vanishes on H, so |h| ≤ L|q|.
- Write ∇q = aT + Y with T unit future timelike, Y ⊥ T and a < 0 bounded away from 0. For future causal X = T + n,
  |n| ≤ 1, dq(X) ≥ |a| − |Y| = −h/(|a| + |Y|).
- So along a future causal curve parametrised by background arc length, (q∘c)′ ≥ −C|q∘c| wherever q∘c < 0. Gronwall
  then gives q∘c ≥ 0. With f := min(p, q) the same argument covers the corner.
- In the first reader's version h vanishes on {q ≥ 0}, so it vanishes even to infinite order.

So the first reader's claim was true but unproved; the argument above is what it lacked. The writer's construction
needs no such argument, and its own correctness does not depend on the report's reason. Nothing in the file needs to
change for this; I record it because the brief asked.
