## Findings

### Criterion (19): the case T⁰¹ = 0, T⁰⁰ + T¹¹ = 0 (discrepancy)

- **The paper states** (eq. (19), p. 13), citing ref. [83]:
  - (T⁰⁰ + T¹¹)² > 4(T⁰¹)² ⇒ type I;
  - (T⁰⁰ + T¹¹)² = 4(T⁰¹)² ⇒ type II;
  - (T⁰⁰ + T¹¹)² < 4(T⁰¹)² ⇒ type IV.
- **What we find:**
  - The eigen-discriminant of the (0,1) block of T^a_b is exactly (T⁰⁰ + T¹¹)² − 4(T⁰¹)². So (19) is the right test in general.
  - In the case T⁰¹ = 0 with T⁰⁰ + T¹¹ = 0, the discriminant vanishes and (19) as printed assigns type II. But the block is then already diagonal, and Maeda-Harada's Lemma 1 makes every T⁰¹ = 0 case type I.
  - This case has measure zero. It does not touch the type-IV verdict, the polynomial below (19), or Fig. 9.
- **Shown by:** `research/warp-drive/docket67-raw/rederive/2505.02210-energy-conditions.py` (check B and the note it prints: "(19) as printed assigns T01 = 0, T00+T11 = 0 to type II; Maeda-Harada Lemma 1 (the paper's ref [83]) makes every T01 = 0 case type I"); `research/warp-drive/docket67-raw/shards/shard08.json`, key `2505.02210-energy-conditions`, `rederivation.outcome` (B).
- **Class:** discrepancy.

### Eqs. (23), (28) and (30): the Λ-scaling (discrepancy)

- **The paper states:**
  - (23), p. 15: the Fubini-Study metric with prefactor (6/Λ)/(1 + r²);
  - (28), p. 18: the Euler-angle coordinates x = √(6/Λ) tan(χ√(Λ/6)) cos(θ/2) cos(ψ/2 + φ/2), and so on;
  - (30), p. 19: the metric that results, with A²(χ) = (1/4)(6/Λ) sin²(χ√(Λ/6)) and B²(χ) = cos²(χ√(Λ/6)).
- **What we find:**
  - At Λ = 6, the paper's numerical value, (23) pulled back by (28) equals (30): the largest difference is 1.35 × 10⁻¹³.
  - For Λ ≠ 6 it does not. The largest component difference is 10.6, at Λ ∈ {0.5, 2, 20}.
  - Either of two repairs restores (30):
    - dropping the √(6/Λ) prefactor from (28) (agreement to 2.1 × 10⁻¹³);
    - rescaling (23) to (1/(1 + Λr²/6))[δ − (Λ/6)(xx + x̃x̃)/(1 + Λr²/6)] (agreement to 4.8 × 10⁻¹³).
  - Λ is a free scale, so nothing downstream moves. The junction values and eqs. (34), (37), (38) and (40) check.
- **Shown by:** `rederive/2505.02210.py` and `.out` (C10a and C10a′); `research/warp-drive/docket67-raw/shards/shard07.json`, key `2505.02210`, `grade_evidence` and `rederivation.outcome`.
- **Class:** discrepancy (scale convention).

## What stands

These were re-derived independently: 36 of 36 checks in `rederive/2505.02210.py`, and 14 of 14 in `rederive/2505.02210-energy-conditions.py`.

- **The energy-condition hierarchy** of Sec. II.A. z3 returns unsat for "type IV and T(k,k) ≥ 0 for both null directions", so type IV violates the NEC.
- **Eqs. (11)-(14).** (12) follows from (11), and (13) and (14) are coordinate forms of it.
- **The tetrad (18a)-(18c).**
- **The sign test.** (T⁰⁰ + T¹¹)² − 4(T⁰¹)² equals a positive factor times the polynomial printed below (19), exactly. So the paper's sign test is correct, and a type-IV region exists.
- **The type-IV point** p = (1, 0, 0, 0) in the U₁ chart. G^a_b there has a complex eigenvalue pair, independent of frame. The paper only "argue[s]" this point, and the computation bears it out.
- **The topology.** The Misner-trick χ arithmetic and the kink number (eqs. (9)-(10) give kink = 1).
- **The footnote-9 curve.** It is a closed, timelike, future-directed curve at Λ = 1, 6 and 100.
- **The junction conditions.** Eqs. (34), (37), (38) and (40).
