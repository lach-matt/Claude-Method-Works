## Findings

### 1. Eq. (36), the boundary of stability region II. Class: discrepancy (minor)

**What the paper states.** Eq. (36) gives stability region II as "β_0² ≤ −1/2, a_0 > a_0⁻".

**What we found.**
- The boundary −1/2 is reached only as a_0 → ∞: for 0 < u < 1/3 the right-hand side of (31) lies strictly below −1/2. At exactly β_0² = −1/2 no finite a_0 is stable.
- So the inequality should be strict. The paper's next sentence, "For −1/2 < β_0² < 3/2 + √3, the wormhole is unstable for all values of a_0", is consistent with either reading.

This is a boundary nicety and changes none of the paper's conclusions.

**What shows it.**
- `rederive/gr-qc_9506083.py`. Re-run 2026-10-04, it prints "NOTE: PV (36) prints 'beta0^2 <= -1/2'; at exactly -1/2 no finite a0 is stable".
- `shards/shard11.json`, key `gr-qc/9506083`, rederivation.outcome. The shard's adversarial verifier, reading the paper independently, finds the left side of (29) at β² = −1/2 equal to M(2a − 3M)/(a(a − 2M)) > 0, i.e. not stable.

### 2. Sec. IV, the Casimir example. Class: discrepancy (notation)

**What the paper states.** Sec. IV gives the Casimir example as "β² = ∂σ/∂p = −1", while (23) defines β² ≡ ∂p/∂σ.

**What we found.** The derivative is written inverted. For the surface stress-energy the paper describes, p = −σ, so ∂p/∂σ = ∂σ/∂p = −1 and the value is unaffected.

**What shows it.** `rederive/gr-qc_9506083.py`, which prints the note "PV sec IV writes the Casimir slope as 'beta^2 = d sigma/d p = -1'; for p = -sigma, dp/dsigma = dsigma/dp = -1, so the value is unaffected"; and `shards/shard11.json`, key `gr-qc/9506083`, rederivation.outcome.
