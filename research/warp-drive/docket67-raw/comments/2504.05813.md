## Summary

The Misner-Sharp relations we re-derived stand, and our one finding does not reach the method or the numerical results, which we did not re-run. That finding is a point of **presentation**. The constraint (2.5) is printed with the positive square root, Γ = +√(1 + U² − 2M/R). That root silently assumes R′ > 0, while the paper's own subject, type-II fluctuations, has Γ < 0 in the throat region. The squared constraint holds on both branches, and the paper's procedure already avoids using the root where Γ < 0. So this is a discrepancy in how (2.5) is stated. It is not a point about the method or the results.

## Finding

### Eq. (2.5): the sign of the root (discrepancy, presentation)

- **The paper states** (eq. (2.5), p. 3): Γ = √(1 + U² − 2M/R), "where Γ is called the generalised Lorentz factor" (p. 4), with Γ ≡ D_r R = R′/B (eq. (2.3)).
- **What we find:**
  - Γ = R′/B is negative wherever R′ < 0. The positive root is right only where R′ > 0, which is always so in the type-I literature the formalism comes from.
  - The paper's own type-II fluctuations have Γ < 0. The paper says so itself: on p. 5, "Γ takes negative values in the throat structure"; on p. 12, "the throat-neck structure in the areal radius R … causes the function Γ to take negative values".
  - The squared form, Γ² = 1 + U² − 2M/R, holds on both branches. With the geometric Misner-Sharp mass it is an identity of the metric (residual 0).
  - The paper already avoids the root where it would fail. On p. 5 it obtains M from the constraint in the squared form (2.24), M = (R/2)(1 + U² − Γ²), and evolves Γ through (2.21) "since Γ takes negative values in the throat structure".
  - Writing (2.5) as Γ² = 1 + U² − 2M/R, or as Γ = ±√(…) with the sign of R′, would remove the ambiguity. A paper from the same group (arXiv:2505.00366, p. 4) writes ±√(1 + 2E) across a neck.
- **Shown by:** `research/warp-drive/docket67-raw/rederive/2504.05813.py` (check A: Γ² − (1 + U² − 2M/R) = 0 in a general diagonal metric with the geometric Misner-Sharp mass; check D: on the far side of a static throat, R = √(1 + 4l²) at l = −10, Γ = −1.997505, so Γ = +√(…) fails while the squared identity holds); `research/warp-drive/docket67-raw/shards/shard09.json`, key `2504.05813`, `lacked_data` and `hypothesis_drift` (the H6 item).
- **Class:** discrepancy (presentation).

## What stands

- **The Misner-Sharp system.** Eqs. (2.1)-(2.5) and (2.12), re-derived with residual 0, together with the comoving-slicing, zero-shift and perfect-fluid hypotheses under which (2.4) holds.
- **The squared constraint.** It holds on both branches.
- **The paper's own procedure respects the branch.** It evolves Γ by (2.21) and obtains M from the squared form (2.24) (printed p. 5), and it sets the initial Γ from Γ = R′/B (printed p. 9). None of these uses the positive root, so the finding does not reach them.
