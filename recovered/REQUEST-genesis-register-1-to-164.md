## 1. The canonical entry form — match it exactly

One entry per event, in the order the work happened. Each entry is a single paragraph:

```
### N

**A CAPITALISED HEADLINE, ENDING IN A PERIOD.** *The body, in italics, ending in a period.*
```

- Fixed density. Each entry stands alone and is self-contained.
- Nothing decorative: an entry exists because something rests on it (a later result, a correction, a
  reference).
- **Corrections keep both states** — what was written wrong and what put it right — and name the entry
  corrected (`register N`).
- **Measurements** carry the number and what it was measured on.
- **Prior art** names the published source.

**The seam anchor.** The entry that immediately *follows* your block in the destination is our entry 165:

```
### 165

**FIBRE CARDINALITY AS AN ORDER SEED.** *Proposed as a seed-independent break; fails to recover Λ's order.*
```

before "fibre cardinality as an order seed" — the point at which the order-recovery question opens.
