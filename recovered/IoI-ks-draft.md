## The Kreuzer–Skarke frontier

**The Calabi–Yau catalogue, indexed by its two Hodge numbers.** An index the method reaches well outside physics as the book uses it elsewhere — the reflexive-polytope list of string compactifications, drawn beside Λ to show the operator travels. §31.3.

**E = 540 on a specifiable slice.** The full catalogue is a file this work could not read, but one slice is stated exactly in print: the χ = ±6 points have Hodge numbers (h, h+3) and (h+3, h) for 13 ≤ h ≤ 128 with named exclusions — a complete set of **208 cells**. Closing it admits **540 cells** — 498 join failures and 498 meet failures of 21,528 pairs. **The 540 are predictions, not a defect**: Hodge pairs the catalogue must contain if the pair set is closed under Batyrev's duality, and the slice cannot contain them for a geometric reason — the join of (h, h+3) and (h+3, h) is (h+3, h+3), so two parallel lines with no fixed point force the diagonal. The closure was cut at χ = ±6 and predicts inward: the admitted cells carry only five distinct Euler characteristics, χ ∈ {0, ±2, ±4}, with 112 on the diagonal from (13, 13) to (131, 131) and h¹¹ + h²¹ running 26 to 262 — the gap between the two lines, which is where the rest of the list lives. This is an index honest about what it proposes and not thereby right; every one of the 540 satisfies the catalogue's published bounds, h¹¹ ≥ 1, h²¹ ≥ 1 and h¹¹ + h²¹ ≤ 502, so none is refuted, but the file to confirm them is missing.
