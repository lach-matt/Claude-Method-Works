**M's ruling: no spectra data exists for any element with 6d.** The record is silent about
6f, 7d, 7f, 8d, 8f at Z=89 because there was never an external witness to be silent about.

**REFINEMENT, RECORDED SO THE RULING IS NOT OVERSTATED LATER.** Ac I's GROUND
configuration is observed — nlchain.jsonl carries `prov: OBSERVED`, rec_cfg 6d1 7s2 at
Z=89, and the row is scored against it. What does not exist is measured data for the
EXCITED 6f, 7d, 7f, 8d, 8f configurations of actinium. **That is exactly the five channels
in question, so the ruling holds where it is applied.**

**THE CONSEQUENCE, AND IT CUTS BOTH WAYS.** The derivation forbids empirical input as a
foundation, so absent spectra cost the derivation nothing — spectra could only ever have
been a witness, never an input. **But it removes the only external cross-check on those
five channels, so the internal argument must carry them alone.** There is no fallback.
That is why item 1 is first.
