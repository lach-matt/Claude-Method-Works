## Mechanism, stated before the numbers
FINDING-TERMS §2 established gap_term - gap_avg = dE_s - dE_d: the NEUTRAL CANCELS. The same algebra holds for ANY additive state energy, so
        gap_SO - gap_LS = so(ion_s) - so(ion_d),
and SO also enters the gap ONLY through the two ions. Landé, first order, ground level of each ion:
    E_SO = (A/2)[J(J+1) - L(L+1) - S(S+1)],  A = +zeta/(2S) for a less-than-half-filled shell, A = -zeta/(2S) for more-than-half.
Class B (Hf Th Rf): d-removed ion d^1 2D_3/2 -> E = -1.5 zeta_d.  s-removed ion d^2 s^1 4F_3/2, A = zeta_d/3 -> E = -2.0 zeta_d.
    so(ion_s) - so(ion_d) = -0.5 zeta_d  <  0.
Class C (Pa U Cm): d-removed ion f^n (SO of the f shell alone). s-removed ion f^n d^1 s^1 — THE SAME f^n PLUS a d electron that the d-removed ion
    has lost. To first order the f^n part is common and cancels, leaving the extra d electron's SO: so(ion_s) - so(ion_d) ~ -1.5 zeta_d < 0.
Class A (Sc Y La Lu Ac): d-removed ion CLOSED (E_SO = 0); s-removed ion d^1 s^1 3D_1, A = zeta_d/2 -> E = -1.5 zeta_d. Difference -1.5 zeta_d < 0.
