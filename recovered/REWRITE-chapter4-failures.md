## 4. The failures of the assistant, and the protocol each one earns

**Ten mechanisms, each earned by a failure that actually happened.** They are not a taxonomy assembled in advance; every one was extracted from the register after the fact, and §28.7.8 groups the entries behind each.

| | the failure | the protocol it earns |
|---|---|---|
| 4.1 | attributed outward before checking inward | a recomputation must suspect the model before it suspects the text |
| 4.2 | wrote into a structure without reading it | enumerate the targets before writing |
| 4.3 | a claim of completion is a claim | verify completion in the pass that claims it |
| 4.4 | a count kept by judgement | read the list; do not carry the number |
| 4.5 | a conclusion written before the output | the order matters even when the answer is right |
| 4.6 | a test that could not fail | exhibit the failure mode before trusting the pass |
| 4.7 | a flag is a hypothesis | localise a detector's output before filing it as a defect |
| 4.8 | a reading the source never made | an assumption is the reader's until the source states it |
| 4.9 | a coordinate collapsed into a count | ρ, and every scalar standing in for a structure |
| 4.10 | a stale figure left behind its own correction | a figure about the book goes stale the moment the book is written into |

**And §28.7.9 adds a coordinate this list does not have: the *level* at which a fault landed** — the value, the derivation, or the inference. Three of the ten sit at the value, three at the derivation, and four at the inference. That axis merges two the list keeps apart: *a stale figure* (4.10) is a value going stale, and *a conclusion written early* (4.5) is an inference drawn early — the same act at two different depths.

**This chapter is short because the material is the register.** Each mechanism is a name for a class of entry, and the entries themselves are the evidence. An earlier form of this chapter was a heading with no body at all, carrying the word SEVEN while the register held ten — and it was cited as §4.1 and §4.2 throughout a book that never defined them.
