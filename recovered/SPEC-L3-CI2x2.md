# SPEC — L3 RELAXED: THE 2x2 CONFIGURATION-MIXING OBJECT. Route C-b, M's ruling s71.
# DESIGN ONLY. Nothing run. No row read. Written BEFORE the prediction file is hashed.

## 1 · THE OBJECT
For one Z, two configurations A and B of the same parity and the same (L,S):

        H = [ E_A   V ]        S = [ 1   s ]          H c = E S c
            [ V    E_B ]            [ s   1 ]

E_A, E_B are already held: `pb4_terms.py` computes them on the ruling field with each
state's own SCF and its own determinantal term correction. **The only new quantity is V.**
This is the actual relaxation of L3: the exact eigenstate is a superposition, and a single
determinant cannot hold two. A comparison of E_A against E_B is NOT that object; it is
what the archive already has.

## 2 · THE STRUCTURE OF V, DERIVED BEFORE IT IS COMPUTED
A and B differ by ONE electron moved between channels a and b. On a common orbital set the
Slater-Condon rule for a single replacement gives

        V = <a|h|b>  +  SUM_k [ <ak|g|bk> - <ak|g|kb> ]

**(i) The one-body term is zero unless l_a = l_b.** h is spherically symmetric.

**(ii) The direct two-body term is zero at every multipole.** It would require the spectator
to absorb zero angular momentum while the promoted electron changes l.

**(iii) A CLOSED spectator shell contributes zero, and so does an OPEN shell that has been
spherically averaged.** Summed over a closed set the two-body sum reconstructs the
spherically symmetric Fock element F_ab, which vanishes for l_a =/= l_b. Under
average-of-configuration the open shell is spherically averaged too, and vanishes with it.
**Therefore V is created entirely by the departure from average-of-configuration.
L3 and L4 are not independent objects: the off-diagonal element L3 needs is generated by
exactly the non-sphericity L4 removes.** The machinery that supplies V is therefore
`hfterm.py` / `nlterm.py`, already sealed, already gated, carrying no constant beyond c.

**(iv) AND A SELECTION RULE FALLS OUT.** The surviving exchange term R^kappa(a k; k b)
carries two 3j factors, requiring
        l_a + l_k + kappa  even     AND     l_k + l_b + kappa  even
Subtracting: **l_a + l_b must be EVEN.** Hence

        s <-> d   ALLOWED   (0+2)      s <-> p   FORBIDDEN  (0+1)
        d <-> d   ALLOWED             p <-> d   FORBIDDEN  (1+2)
        s <-> s   ALLOWED             d <-> f   FORBIDDEN  (2+3)
        f <-> f   ALLOWED             s <-> f   FORBIDDEN  (0+3)

**This is the whole design consequence and it partitions the open work exactly along the
line the solution already draws.** The s<->d promotions — Cr, Cu, Nb, Mo, Ru, Rh, Pd, Ag,
Pt, Au — are the ALLOWED case. The d<->f competitions that carry the tie-break — La/Ce,
Ac/Th/Pa — are PARITY-FORBIDDEN and V is identically zero there.

## 3 · WHAT THE OBJECT CAN AND CANNOT DECIDE, IF THE STRUCTURE HOLDS
It can move the CONFIGURATION COLUMN (73/107) at the s<->d rows. It cannot touch a
tie-break row. And at a FIRST-ENTRY row the partner channel is unoccupied, so there is no
open spectator shell to carry the exchange at all — V = 0 by occupancy as well as by parity.
**If that holds, the ORDERING clause and the period lengths are immune to L3 by
DERIVATION rather than by bound**, which is the standard M's ruling of s70 demands.
