## D. Setting
D1. Coordinates i = 1..d, each with a finite chain of values. A cell is a d-tuple; an index
    X is a finite set of cells. Alphabet: Â_i(X) = { x_i : x ∈ X }.
D2. Envelope: for i ≠ j and t ∈ Â_j(X), φ̂_ij^X(t) = max{ c_i : c ∈ X, c_j ≤ t }.
    (Well-defined for t ≥ min Â_j(X); the operative domain below is Â_j(Λ).)
D3. Closure (the book's ℛ, verbatim from the sealed instrument):
    ℛ(X) = { x ∈ ∏_i Â_i(X) : x_i ≤ φ̂_ij^X(x_j) for all i ≠ j }.
D4. Throughout, Λ is closed: ℛ(Λ) = Λ (E(Λ) = 0, L.E0). X₀ ⊆ Λ GENERATES Λ if ℛ(X₀) = Λ.
    seed(Λ) = the minimum |X₀| over generating X₀.

## L1. Envelope monotonicity
For fixed i,j and X, the map t ↦ φ̂_ij^X(t) is non-decreasing on Â_j(X); and X₀ ⊆ X implies
φ̂_ij^{X₀}(t) ≤ φ̂_ij^X(t) wherever the left side is defined.
*Proof.* The defining set { c : c_j ≤ t } grows with t and with X; max is monotone in the set. ∎

## T1. The generation criterion (exactness of the covering formulation)
X₀ ⊆ Λ generates Λ **iff** (a) Â_i(X₀) = Â_i(Λ) for every i, and
(b) φ̂_ij^{X₀}(t) = φ̂_ij^Λ(t) for every i ≠ j and every t ∈ Â_j(Λ).
*Proof.* (⇒) Suppose ℛ(X₀) = Λ. By D3, ℛ(X₀) ⊆ ∏ Â_i(X₀); hence Λ ⊆ ∏ Â_i(X₀), so
Â_i(Λ) = π_i(Λ) ⊆ Â_i(X₀); with X₀ ⊆ Λ the reverse holds, giving (a). For (b): ≤ is L1.
For ≥, fix t ∈ Â_j(Λ) and let M = φ̂_ij^Λ(t), achieved by c* ∈ Λ with c*_j ≤ t, c*_i = M.
Since c* ∈ Λ = ℛ(X₀), D3 gives M = c*_i ≤ φ̂_ij^{X₀}(c*_j) ≤ φ̂_ij^{X₀}(t) by L1.
(⇐) Given (a), the two closures are carved from the same box ∏ Â_i(Λ); given (b), by the same
inequalities in D3 they impose identical constraints; hence ℛ(X₀) = ℛ(Λ) = Λ, using E(Λ)=0. ∎
*Remark.* This is the theorem the two-route validation measured: 200/200 exact covers closed
to |Λ| = 976 under the sealed Rn; and it licenses the set-cover formulation (elements =
alphabet slots ∪ envelope steps; a cell covers what it witnesses).

## T2. The alphabet law (property 4, now a law)
Every generating X₀ witnesses every alphabet value of every coordinate; in particular, for
each i some cell of X₀ has x_i = min Â_i(Λ) and some cell has x_i = max Â_i(Λ).
Bit-reading corollary: writing 1 for a coordinate at its maximum and 0 at its minimum, every
column receives both a 0 and a 1 across any seed — at any cap — provided |Â_i(Λ)| ≥ 2
(a singleton alphabet receives one symbol; no cap of Λ tested has one).
*Proof.* Immediate from T1(a). Cap-independence: the proof uses only D1–D4, never a cap. ∎

## C2.1. Null and full transitions (corollaries of T2)
(i) 0 ∈ Â_q(Λ) (L.c3 admits q = 0), so every seed contains a null transition q = 0.
(ii) Let q̄ = max Â_q(Λ) = max Â_k(Λ) = k̄ (q = k is admitted whenever k is, L.c3, and
q ≤ k ≤ k̄). A seed cell witnessing q = q̄ has q̄ = q ≤ k ≤ k̄ = q̄, forcing k = q — a full
transfer. So every seed contains a full transfer q = k. ∎
*Both were measured element-forced at all four cap settings tested.*

## T3. The envelope-step law
Call (i, j, t) a STEP of Λ if t ∈ Â_j(Λ) is minimal with φ̂_ij^Λ(t) at its value — i.e.
t = min Â_j(Λ) or φ̂_ij^Λ(t) > φ̂_ij^Λ(t⁻) for t⁻ the predecessor of t in Â_j(Λ).
Then every generating X₀ contains, for each step (i, j, t), a cell c with c_j ≤ t and
c_i = φ̂_ij^Λ(t); and since c ∈ Λ with c_j ≤ t implies c_i ≤ φ̂_ij^Λ(t), the equality is exact.
*Proof.* By T1(b), φ̂_ij^{X₀}(t) = φ̂_ij^Λ(t) =: V. The left side is a max over the nonempty
set { c ∈ X₀ : c_j ≤ t }, attained by some c; c_i = V by the sandwich above. Conversely,
covering all steps (with all alphabet slots) suffices, because the running max of φ̂ between
steps is constant, so equality at steps propagates to all of Â_j(Λ) — which with T1(⇐) closes. ∎
*Specialization.* At (i, j) = (f, ℓ), t = min Â_ℓ: the seed contains a cell at ℓ-min carrying
the maximum f attainable there — s→p at ℓ-cap 1, s→d at ℓ-cap 2 (both measured element-forced).
Symmetrically (ℓ, f) at f-min gives ℓ-max with f-min (p→s, d→s). The recorded six channel
conditions of R 603 are the ℓ≤1 face of this law; s→s is not a step and was never forced
(measured: 71% of exact covers at Λ₈).

## P4. Non-uniqueness, located in the literature (the negative half)
An element x is EXTREME (Edelman) if x ∉ ℛ(Λ∖{x}). On record: ℛ(Λ∖{x}) = Λ for all 976 cells
— Λ₈ has NO extreme points. A closure space in which every closed set is generated by its
extreme points is exactly a convex geometry (anti-exchange closure; Edelman–Jamison), the
combinatorial Krein–Milman property. ℛ on Λ₈ fails it maximally: the extreme-point set is ∅
yet seed = 7. Consequently no unique minimum generating set exists; the multiplicity is
measured at 24,585 at the Λ₈ cap. What IS common to all minimum covers is not an extreme
point but a FORCED SET of the derived cover instance (Chvátal's reduction): at Λ₈, exactly
one cell, (2,1,3,3,2,1,3,0); and that forcing is cap-specific (falls at the d-shell cap).
*Moral: the seed's invariant content is T2 + T3 — alphabet slots and envelope steps — not
cell identities. The complement pairings of §14.5.14 (properties 1–3) are properties of a
219-cover sample of a 24,585-cover set, refuted at Λ₈ itself; corner 4 (11001100) appears in
14% of exact covers, the unit template in 10%.*
